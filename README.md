# TAS Nexus

TAS Nexus web pages, published with GitHub Pages.

Site: https://ProfessorLeVesseur.github.io/tas-nexus/

Sales Cube overview: https://ProfessorLeVesseur.github.io/tas-nexus/sales-cube.html
(`sales-cube.html`, including its embedded illustrative dashboard).

## Updating the homepage

The homepage is `index.html`. It contains its own styles and JavaScript.
Edit or replace it on the `main` branch; GitHub Pages publishes changes
automatically. Publishing can take a few minutes.

## Adding more pages

Upload additional HTML files to this repository using **Add file > Upload files**,
then commit to `main`. For example, `example.html` will be available at
`https://ProfessorLeVesseur.github.io/tas-nexus/example.html`.

Include any images, CSS, and JavaScript those pages need. Use relative links
such as `images/logo.png` or `example.html` so they work under `/tas-nexus/`.

## Publishing settings

In **Settings > Pages**, use **Deploy from a branch**, select `main` and
`/ (root)`, and save.

This repository and its published pages are public. Do not upload confidential
data or credentials.
